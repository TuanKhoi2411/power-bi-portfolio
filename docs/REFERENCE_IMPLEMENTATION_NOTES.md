## Structural ideas adapted

- A full copy-ready dashboard creation prompt rather than a short README summary.
- Separate human-readable DAX, metric definitions, data dictionary, relationship map, and semantic-model notes.
- Separate Power Query/PBIX build instructions.
- Explicit QA checklist, structural evidence, validation result, and limitation disclosure.
- Clear distinction between build-ready structure and verified Power BI Desktop completion.
- Rebuild instructions visible from each project's README.

## What was not copied

- FP&A project content, synthetic data, dashboard pages, themes, DAX formulas, business results, and filenames from the reference repository.
- Claims that do not apply to the current artifacts.

The Sales, Marketing, and Apple Finance packages in this repository are generated from their own current PBIP/PBIR/TMDL, included public sources, and recovered creation-task history.
