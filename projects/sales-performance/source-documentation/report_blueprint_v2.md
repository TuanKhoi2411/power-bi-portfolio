# Report blueprint v2

## Shared design

Keep the existing three-page 1280×720 grid: dark header, primary date slicer top-right, left navigation/filter rail, five KPI cards, compact sparklines, and a two-row analysis zone. Avoid decorative visuals.

## Page 1 — UK Retail Sales

Decision: assess net/gross sales, orders, units, returns, geography, product breadth, and short-term momentum. The main trend compares every month with its immediately preceding month; the partial latest month remains disclosed separately.

## Page 2 — Customer Insights

Decision: separate identified-customer behavior from anonymous revenue. KPI 4 uses identified orders per customer; KPI 5 uses net-sales coverage. The main composition chart stacks identified and anonymous sales so the coverage gap is visually explicit.

## Page 3 — Product & Returns

Decision: locate high-value products and return exposure. Keep merchandise filters that exclude administrative descriptions/codes.

## Manual enhancement note

If a small text card is added in Desktop, bind it to Latest Period Status. Do not enlarge the canvas or add a fourth page solely for this note.
