# Measure catalog v2

| Measure | Definition | Purpose | Visible use |
|---|---|---|---|
| Segment Conversion Rate (500+ Contacts) | Conversion Rate when Contacts ≥ 500 | Prevents small-base ranking | Job/Age ranking charts |
| Segment Conversions per 1K (500+ Contacts) | per-1K conversion when Contacts ≥ 500 | Comparable efficiency with base guardrail | Available for segment visuals/tooltips |
| Sample Size Status | <100, 100–499, or 500+ | Human-readable uncertainty flag | Detail/tooltip candidate |
| Duration Leakage Warning | fixed warning text | Prevents pre-call misuse | Tooltip/manual note candidate |
| Contact Share | Contacts / all contacts | Shows volume mix | Segment analysis/tooltips |

Core validated measures remain Contacts, Conversions, Conversion Rate, Conversions per 1K, Average Contact Duration, Average Campaign Contacts, Prior Contact Rate, Cellular Contact Share, and Successful Prior Outcome Rate.
# Conversion direction display

`Conversion Rate Change Display` converts the existing month-over-month percentage-point variance into an explicit ▲/▼ label for KPI cards while retaining the numeric measure for charts and tables.

`Conversion Contribution` shows each month's share of campaign conversions while preserving other report filters; it drives the Overview contribution chart.
