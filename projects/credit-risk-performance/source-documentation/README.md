# FinTech Credit Risk Analytics

Open `FinTech_Credit_Risk.pbip` in Power BI Desktop.

## Report pages

1. **Portfolio Overview** — portfolio size, funded value, applications, outstanding principal, bad-loan rate, state/purpose concentration, loan-quality mix and monthly movement.
2. **Borrower Risk** — borrower count, average ticket, repeat borrowing, income verification, income-band risk and verification trends.
3. **Recovery & Rules** — grade breadth, recovery rate, outstanding principal, low-recovery exposure, pricing, purpose-level recovery and grade/purpose detail.

The project is fully source-controlled PBIP: report definitions are PBIR JSON, the semantic model is TMDL, and Power Query loads the CSV in the parent `CP2 - New` folder.
