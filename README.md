# Power BI Analytics Portfolio

A Power BI dashboard project by **Nguyen Tuan Khoi**, created to demonstrate analytical thinking, dashboard design, data storytelling, and business-focused reporting.

## Dashboard structure

The report contains four focused pages:

- **Overview** - executive-level performance summary
- **Breakdown** - detailed analysis of key drivers
- **Segments** - comparison across business segments
- **Breakeven** - break-even and profitability analysis
